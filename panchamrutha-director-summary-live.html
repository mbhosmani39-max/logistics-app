About this report

  • This report reads directly from the same shared trip register as the operational app — it updates automatically as trip sheets are added, edited, or closed. No manual refresh of data needed, just reload the page for the latest figures.
  • Freight revenue includes third-party goods lines and lorry-return-freight amounts across all trips; own-goods (Panchamrutha rice) legs carry zero freight by design.
  • This is a revenue view only — it does not include cost-side numbers (fuel, batta, tolls, maintenance), so it is not a profitability report.
